ابزاری سبک برای بررسی خودکار صفحات نوبت‌دهی پزشکان و ارسال اعلان در تلگرام هنگام پیدا شدن نوبت آزاد.

این پروژه در حال حاضر از **DoctorTo** پشتیبانی می‌کند و به‌گونه‌ای طراحی شده که در آینده سایت‌های نوبت‌دهی دیگر نیز با مشارکت جامعه توسعه‌دهندگان به آن اضافه شوند.

---

## **✨ ویژگی‌ها**

* بررسی خودکار صفحه نوبت‌دهی پزشک
* تشخیص نوبت‌های آزاد جدید
* ارسال اعلان از طریق تلگرام
* جلوگیری از ارسال اعلان تکراری برای یک وضعیت مشابه
* ذخیره تنظیمات به‌صورت محلی
* امکان تغییر پزشک موردنظر در هر زمان
* اجرای مداوم با بازه بررسی قابل تنظیم
* پشتیبانی از نام فارسی و Unicode پزشکان
* سازگار با Termux
* بدون نیاز به دیتابیس
* استفاده از Python Standard Library
* طراحی‌شده برای اضافه‌شدن آسان سایت‌های جدید

# **🚀 نصب**

ابتدا Repository را Clone کنید:

```
git clone https://github.com/hosseinzamaninasab/doctor-appointment-watcher.git
cd doctor-appointment-watcher
```

سپس:

```
chmod +x setup.sh
./setup.sh
```

اسکریپت راه‌اندازی محیط Termux را آماده کرده و برنامه را اجرا می‌کند.

---

# **🆕 اجرای اول**

در اولین اجرا، چون هنوز تنظیماتی وجود ندارد، برنامه به‌صورت خودکار Setup اولیه را شروع می‌کند.

اطلاعات موردنیاز:

1. لینک صفحه پزشک
2. نام پزشک
3. Telegram Bot Token
4. Telegram Chat
5. بازه بررسی

⠀
مثال:

```
=== Doctor Appointment Watcher Setup ===

Doctor URL:
> https://doctoreto.com/doctor/...

Doctor name:
> نام و نام خانوادگی دکتر

Telegram Bot Token:
> ********

Open your bot in Telegram and press Start.

Setup completed successfully.
```

تنظیمات به‌صورت محلی ذخیره می‌شوند و در اجرای بعدی نیازی به واردکردن دوباره اطلاعات نیست.

---

# **▶️ اجرای برنامه**

برای اجرای برنامه:

```
./setup.sh
```

یا:

```
python appointment_watcher.py
```

اگر تنظیمات قبلی وجود داشته باشند، منوی زیر نمایش داده می‌شود:

```
=== Doctor Appointment Watcher ===

1) Start watcher
2) Configure another doctor
3) Exit
```

## **شروع پایش**

گزینه زیر را انتخاب کنید:

```
1
```

برنامه پزشک فعلی را به‌صورت دوره‌ای بررسی می‌کند.

## **تغییر پزشک**

برای تنظیم پزشک جدید:

```
2
```

اطلاعات پزشک جدید جایگزین تنظیمات قبلی می‌شوند و وضعیت پایش قبلی نیز Reset می‌شود.

بنابراین برای تغییر پزشک نیازی به حذف دستی فایل‌های تنظیمات نیست.

## **خروج**

برای خروج:

```
3
```

---

# **⛔ توقف Watcher**

برای توقف برنامه:

```
Ctrl + C
```

در Termux، در صورتی که کلید Ctrl در دسترس نیست، معمولاً می‌توانید از:

```
Volume Down + C
```

استفاده کنید.

```
        ↓

        ↓

       ↙        ↘
      بله        خیر
       ↓          ↓

```

برنامه مقدار کمی اطلاعات را به‌صورت محلی ذخیره می‌کند تا برای یک نوبت مشابه، اعلان تکراری ارسال نشود.

---

# **🔐 حریم خصوصی و تنظیمات**

برنامه ممکن است اطلاعات زیر را به‌صورت محلی ذخیره کند:

* اطلاعات پزشک
* لینک صفحه پزشک
* Telegram Bot Token
* Telegram Chat ID
فایل تنظیمات در محل زیر ذخیره می‌شود:

```
~/.config/doctoreto-watcher/
```

این اطلاعات را با دیگران به اشتراک نگذارید.

به‌خصوص Telegram Bot Token باید مانند رمز عبور محافظت شود.

اگر Token به‌صورت عمومی منتشر شد، فوراً آن را از طریق BotFather لغو و Token جدید ایجاد کنید.
